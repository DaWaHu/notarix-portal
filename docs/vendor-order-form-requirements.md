# Vendor Order Form - Production Requirements

This page is production-approved in concept and must not be simplified or rewritten without preserving all rules below.

## Must preserve
- Vendor code shown at top of page
- Vendor company/account review section auto-populated from stored Vendor record
- Borrower information section
- Property and signing section
- Order preferences section
- Payment fee section
- Submit and cancel actions

## Controlled fields
- Paper Size must be a dropdown with:
  - Both
  - Letter
  - Legal

- Preferred Ink must be a dropdown with:
  - Blue
  - Black

- State must be a dropdown list of U.S. states

- Signing Time must be a dropdown from 6:00 AM to 9:00 PM in 30-minute increments

## Date/time rules
- Signing Date cannot be in the past
- Signing Date can only be selected up to 6 months into the future
- Signing display/label should follow the intended business-friendly format, e.g.:
  - Friday 03/25/2026 at 6PM (EST)

## Payment section
- Payment fee section must exist on the form
- Payment method should support VendorPay as the current intended option
- VendorPay is not fully set up yet, but the form must preserve this path

## Vendor review section
- Must auto-populate from stored Vendor account details where available:
  - vendor code
  - company name
  - company type
  - address fields
  - website
  - primary/secondary phones
  - primary/secondary contact details
  - approval status
  - active status

## Change-control rule
- No full-page rewrites on this page unless explicitly approved
- Make only surgical edits
- Preserve all approved business rules during every change
